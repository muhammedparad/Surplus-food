# Surplus Food

A food rescue and redistribution platform connecting restaurants, NGOs and volunteers to reduce food waste.

## Project Overview

Restaurants can publish surplus food donations, NGOs can request available donations, and volunteers can coordinate food pickup and delivery.

## Technology Stack

- Backend: NestJS
- Database: PostgreSQL
- ORM: Prisma
- Frontend: To be finalized by the team
